# משימות: ניהול משימות אישי

אפליקציית משימות שעובדת בדפדפן וגם מותקנת על הטלפון כאפליקציה (PWA). היא עובדת גם בלי אינטרנט,
ויכולה לסנכרן בין הטלפון למחשב. כל השירותים שהיא משתמשת בהם חינמיים.

| מה | שירות |
|---|---|
| האפליקציה | React + Vite + TypeScript, PWA |
| אירוח | GitHub Pages |
| סנכרון והתחברות (אופציונלי) | Supabase (Free) |

## התחלה מהירה

```bash
npm install
npm run dev        # http://localhost:5173
```
