# מדריך למשתמש

## המסכים

| מסך | מה מוצג |
|---|---|
| **לוח שנה** | לוח חודשי. מתחת לכל יום שיש בו משימות מופיעה נקודה. לוחצים על יום כדי לראות את המשימות שלו ([פירוט](#לוח-שנה)) |
| **היום** | משימות שתאריך היעד שלהן היום, כולל משימות שלא בוצעו בימים קודמים ועברו להיום ([פירוט](#משימה-שלא-בוצעה-עוברת-ליום-הבא)). משימות שהושלמו היום מופיעות בסוף, בחלק מקופל |
| **פתקים** | דברים בלי תאריך שמנהלים לאורך זמן: יום אחד, לקנות, ספרים, חבילות, החזרים, שיער, ריסים, גלולות ורכב ([פירוט](#פתקים)) |
| **הושלמו** | משימות שסומנו כבוצעו. החדשות ביותר למעלה |
| **סיכום** | כמה הושלם וכמה פתוח, גרף של 7 הימים האחרונים, והמשימות שנדחו הכי הרבה ([פירוט](#סיכום)) |
| **סל מחזור** | משימות שנמחקו ב-30 הימים האחרונים ([פירוט](#סל-מחזור)) |
| **רשימה** (למשל "עבודה") | המשימות של הרשימה, ובסוף החלק "הושלמו" |

**במחשב** המסכים והרשימות מופיעים בתפריט הצד.
**בטלפון** יש סרגל ניווט למטה (מימין לשמאל): לוח שנה, היום, פתקים, סיכום, רשימות. הכפתור **רשימות** פותח תפריט עם כל הרשימות, עם "הושלמו" ועם ההגדרות.

האפליקציה נפתחת על **לוח שנה**, כשהיום מסומן והמשימות שלו מוצגות מתחת ללוח.

המספר ליד כל מסך מראה כמה משימות פתוחות יש בו.

האפליקציה בעיצוב כהה בלבד. את צבע ההדגשה אפשר לבחור בהגדרות.

## הוספת משימה

לוחצים על כפתור ה-**+** העגול שבצד ימין למטה. נפתחת חלונית קטנה.
כותבים את המשימה ולוחצים על כפתור החץ (או Enter). המשימה נוספת והחלונית נסגרת. למשימה נוספת לוחצים שוב על ה-+.
כדי לסגור אותה לוחצים מחוץ לחלונית, על Esc או על כפתור "חזור" בטלפון.

מתחת לשורת הכתיבה רואים מראש לאיזה תאריך ולאיזו רשימה המשימה תיכנס:

- משימה שנוספת במסך **היום** מקבלת את התאריך של היום.
- משימה שנוספת ב**פתקים ← יום אחד** נשארת בלי תאריך.
- משימה שנוספת ב**לוח שנה** מקבלת את התאריך של היום הנבחר.
- משימה שנוספת בתוך **רשימה** משויכת לרשימה הזו.

במסך "הושלמו", בחיפוש, בסיכום ובמסך הראשי של "פתקים" אין כפתור +. בשאר הלוחות של "פתקים" ה-+ מוסיף פריט ללוח.

### הוספה בקול 🎤

בחלונית ההוספה לוחצים על כפתור **המיקרופון** ואומרים את המשימה, למשל: "ב־25.11 יש לי פסיכולוגית".
הטקסט נכתב לשורה תוך כדי דיבור. מתחת לשורה מופיע התאריך שזוהה ("יום רביעי, 25 בנובמבר").
אם הכול נכון, לוחצים על החץ. התוצאה במקרה הזה: משימה בשם "פסיכולוגית" בתאריך 25 בנובמבר.

- **עובד ב:** Chrome, Edge ו-Safari. דורש חיבור לאינטרנט, כי הדפדפן שולח את הקול לשירות הזיהוי של Google, Microsoft או Apple.
- **בפעם הראשונה** הדפדפן מבקש הרשאה למיקרופון. צריך לאשר.
- **מגבלות:**
  - המיקרופון עובד רק בכתובת מאובטחת: `localhost` במחשב, או האתר אחרי פריסה. בטלפון דרך כתובת רשת מקומית (`http://192.168…`) הוא לא יעבוד.
  - בדפדפנים שלא תומכים בזיהוי דיבור (Firefox, למשל) כפתור המיקרופון לא מופיע.

### קיצורים וזיהוי תאריכים

אותם כללים חלים על הקלדה ועל דיבור:

| כותבים או אומרים | התוצאה |
|---|---|
| `היום` / `מחר` / `מחרתיים` | התאריך המתאים |
| `25.11` / `25/11` / `25.11.2026` | 25 בנובמבר. בלי שנה: השנה הנוכחית, ואם התאריך כבר עבר, השנה הבאה |
| `25 בנובמבר` / `ב-7 לינואר` / `עד ה-30 בנובמבר` | התאריך המתאים |
| `ב-25 לחודש` / `ב-25 בחודש` / `עד ה-30 בחודש` | היום הזה בחודש הנוכחי. אם הוא כבר עבר, בחודש הבא |
| `ב-25 לחודש הבא` | היום הזה בחודש הבא |
| `בעשרים וחמישה לחודש` / `בחמישה בדצמבר` / `בראשון לחודש` | מספרים במילים, כמו שזיהוי הדיבור כותב לפעמים. עובד רק לפני "לחודש" או לפני שם של חודש |
| `ביום שלישי` / `ביום ראשון הבא` / `בשבת` | יום שלישי, ראשון או שבת הקרובים. אם היום יום שלישי, זה יום שלישי של השבוע הבא |
| `בעוד 3 ימים` / `בעוד יומיים` / `בעוד שבוע` / `בעוד שבועיים` | התאריך המתאים |
| `16:30` / `ב-16:30` / `בשעה 9` | שעה. בלי דקות ובלי ציון חלק ביום, השעות 1–7 נחשבות אחר הצהריים |
| `בארבע אחר הצהריים` / `בשמונה בערב` / `בשעה 9 בבוקר` / `בשעה ארבע וחצי` | שעה במילים, עם חלק ביום, "וחצי" או "ורבע" |
| `כל יום` / `בימי חול` / `כל שבוע` / `כל שבועיים` / `כל חודש` / `כל שנה` | משימה חוזרת |
| `כל יום ראשון` | חוזרת כל שבוע, החל מיום ראשון הקרוב (או היום, אם היום יום ראשון) |
| `כל שבועיים ביום ראשון` / `כל שבועיים בשישי` | חוזרת כל שבועיים, החל מהיום הזה הקרוב |
| `כל 10 לחודש` | חוזרת כל חודש ב-10 בחודש |
| `!` / `!!` / `!!!` | עדיפות נמוכה / בינונית / גבוהה |

המילים שזוהו כתאריך יוצאות מהכותרת. גם מילות פתיחה כמו "יש לי", "תזכיר לי", "צריך" ו"אני צריכה" לא נכנסות לכותרת.

דוגמאות:
- `לשלם ארנונה מחר !!!` יוצר את "לשלם ארנונה", מחר, בעדיפות גבוהה.
- `ביום שלישי ישיבת צוות` יוצר את "ישיבת צוות", ביום שלישי הקרוב.
- `ב-25 לחודש בארבע אחר הצהריים פסיכולוגית` יוצר את "פסיכולוגית", ב-25 בחודש בשעה 16:00.
- `כל 10 לחודש לשלם שכירות` יוצר את "לשלם שכירות", שחוזרת ב-10 לכל חודש.

## משימה שלא בוצעה עוברת ליום הבא

משימה פתוחה שתאריך היעד שלה עבר **עוברת אוטומטית להיום**. אין משימות "באיחור", כל מה שלא בוצע פשוט מחכה לך במסך "היום".

- **מתי זה קורה:** בחצות. אם האפליקציה הייתה סגורה, זה קורה בפעם הבאה שפותחים אותה או חוזרים אליה.
- **מונה ימי דחייה:** כל משימה זוכרת כמה ימים היא נדחתה בסך הכול.
  המונה מוצג בכתום מתחת לשם המשימה: "נדחתה ביום", "נדחתה יומיים", "נדחתה 5 ימים".
  - אם האפליקציה לא נפתחה כמה ימים, המונה גדל בכל הימים שעברו. משימה מלפני 3 ימים, למשל, תקבל 3.
  - המונה סופר רק דחיות אוטומטיות. כשמשנים את התאריך ידנית, המונה לא משתנה.
  - כשמשימה שנדחתה מסומנת כבוצעה, המונה נשמר ומוצג: "בוצעה אחרי 4 ימי דחייה".
    משימות שהושלמו מופיעות בחלק המקופל "הושלמו" ובמסך "הושלמו".
- **משימות בלי תאריך** ומשימות שהושלמו לא זזות.

## לוח שנה

- **הנקודות מתחת לימים:**
  - **כחולה:** יש משימות פתוחות.
  - **אפורה:** כל המשימות של היום הזה הושלמו.
  - בימים שעברו בדרך כלל אין נקודה כחולה, כי משימות שלא בוצעו עוברות להיום.
- **היום הנוכחי** מוקף במסגרת. **היום הנבחר** מסומן בעיגול מלא.
- **לחיצה על יום** מציגה מתחת ללוח את המשימות שלו: קודם הפתוחות, ואחריהן אלה שהושלמו.
- **הוספת משימה** בכפתור + משבצת אותה ליום הנבחר.
- **מעבר בין חודשים:** בחצים שליד שם החודש, או בטלפון בהחלקה של הלוח ימינה או שמאלה.
- **כיווץ הלוח:** בטלפון מחליקים את הלוח **למעלה**, ונשארת רק השורה של השבוע הנוכחי, כך שרואים יותר משימות.
  החלקה **למטה** מחזירה את החודש המלא. אפשר גם ללחוץ על הלשונית הקטנה שבתחתית הלוח, וכך עושים את זה במחשב.
  במצב מכווץ החצים עוברים שבוע אחורה או קדימה. האפליקציה זוכרת אם הלוח מכווץ או פתוח.
  הכפתור **היום** מחזיר ליום הנוכחי.
- הלוח מציג רק משימות שיש להן תאריך יעד.

## העברת משימה לתאריך אחר בגרירה

במקום לשנות תאריך בחלון העריכה, אפשר לגרור את המשימה:

- **בלוח שנה:** גוררים משימה מהרשימה שמתחת ללוח אל יום בלוח.

| מכשיר | איך גוררים |
|---|---|
| מחשב | לוחצים על המשימה, מחזיקים את העכבר וגוררים |
| טלפון | לחיצה ארוכה על המשימה (כחצי שנייה, הטלפון ירטוט), ואז גוררים בלי להרים את האצבע |

בזמן הגרירה, היום שמעליו נמצאת המשימה מודגש, ותצוגה צפה מראה לאן היא תעבור.
אחרי השחרור מופיעה הודעה עם כפתור **ביטול**.
גרירה לא משנה את מונה ימי הדחייה, כי המונה סופר רק דחיות אוטומטיות.

## שעה ותזכורת

- **שעה:** בחלון העריכה, בשדה **שעה**, או ישירות בזמן ההוספה (למשל "ב-16:30").
  ביום מסוים, משימות עם שעה מופיעות לפי הסדר שלהן ולפני משימות בלי שעה. השעה מוצגת בצבע ההדגשה מתחת לשם המשימה.
- **תזכורת:** אחרי שבוחרים תאריך ושעה, בוחרים בשדה **תזכורת**: בזמן, 10 דקות לפני, חצי שעה לפני, שעה לפני או יום לפני.
  - בפעם הראשונה הדפדפן מבקש הרשאה להתראות. צריך לאשר.
  - למשימה עם תזכורת יש אייקון פעמון 🔔 בשורה.
  - **בשלב הזה** התזכורת מופיעה רק כשהאפליקציה פתוחה, גם אם היא ברקע (לשונית אחרת או חלון ממוזער).
    תזכורות גם כשהאפליקציה סגורה לגמרי יתווספו כשנעביר את האפליקציה לטלפון.
  - אם המחשב היה כבוי ועברה יותר משעה מזמן התזכורת, היא לא תוצג באיחור.

## משימות חוזרות

לשכר דירה, תרופה יומית, ספורט ביום קבוע וכדומה:

- בחלון העריכה, בשדה **חזרה**, בוחרים: כל יום, ימי חול (א׳–ה׳), כל שבוע, כל שבועיים, כל חודש או כל שנה.
  אפשר גם בזמן ההוספה: "כל יום ראשון ספורט" או "כל 10 לחודש שכירות".
- למשימה חוזרת יש אייקון ↻ עם סוג החזרה.
- **כשמסמנים אותה כבוצעה** נוצרת לבד המשימה הבאה בסדרה, עם אותה שעה, תזכורת, הערות ותת-משימות (לא מסומנות).
  ההודעה אומרת מתי הבאה, למשל "הושלמה · הבאה למחר". **ביטול** מבטל גם את יצירת הבאה.
- "כל חודש" ב-31 בחודש עובר לסוף החודש בחודשים קצרים יותר.
- **ההבדל משכפול:** משימה חוזרת ממשיכה בלי סוף, תמיד רק המשימה הבאה. שכפול יוצר מראש מספר מוגבל של משימות.

## החלקה על משימה (בטלפון)

| פעולה | מה קורה |
|---|---|
| **החלקה ימינה** ⟶ | 🗑 **מחיקה**, בכל המסכים ובכל הלוחות של "פתקים". גם משימה שכבר הושלמה. משימות עוברות לסל המחזור |
| **החלקה שמאלה** ⟵ | **מחר** (רק משימות פתוחות) |

- **מחר:** המשימה עוברת ליום הבא ומונה הדחיות שלה גדל ביום.
- בזמן ההחלקה מופיע מתחת למשימה צבע עם הפעולה (אדום למחיקה), והוא מתחזק כשמגיעים לנקודת ההפעלה.
- לסמן כבוצע: לוחצים על העיגול שליד המשימה.
- לחיצה ארוכה בלוח השנה מפעילה גרירה לתאריך אחר.
- אחרי כל פעולה מופיע **ביטול**. משימה שנמחקה אפשר גם לשחזר מסל המחזור.
- ב"פתקים" יש רק החלקה ימינה (מחיקה), עם **ביטול** בהודעה.

## תת-משימות

בחלון העריכה, בחלק **תת-משימות**:
- כותבים בשורה "+ תת-משימה" ולוחצים Enter.
- מסמנים כל אחת כשהיא בוצעה. אפשר לערוך את הטקסט או למחוק עם ×.

בשורת המשימה מופיע כמה בוצעו מתוך כמה, למשל 1/3. כשכולן בוצעו הספירה נצבעת בירוק.

## חגים ותאריך עברי

- **בלוח השנה:** ימי חג ומועד מסומנים בעיגול רקע עדין סביב המספר, והמספר בגוון בהיר של צבע ההדגשה (לבנדר כברירת מחדל). כשמחליפים צבע בהגדרות, גם סימון החגים מתחלף.
  כשבוחרים יום, הכותרת מראה את התאריך העברי ואת שם החג, למשל "יום שבת, 5 בדצמבר · כ״ה בכסלו תשפ״ז · חנוכה".
- **במסך "היום"** התאריך העברי מופיע ליד התאריך הלועזי, ובחג גם שם החג.
- החגים: ראש השנה, יום כיפור, סוכות ושמחת תורה, חנוכה, ט״ו בשבט, פורים, פסח, יום השואה, יום הזיכרון, יום העצמאות,
  ל״ג בעומר, יום ירושלים, שבועות, תשעה באב, ט״ו באב, וצומות.
  ימי הזיכרון והצומות כוללים את ההזזות שלהם כשהם יוצאים בשבת או בסמוך לה.

## פתקים

מקום לדברים שאין להם יום מסוים ומנהלים אותם לאורך זמן, במקום הפתקים באייפון.
**שינוי הסדר:** בצד שמאל של כל כרטיס יש ידית (⠿). גוררים אותה למעלה או למטה כדי להזיז את הלוח. הסדר נשמר במכשיר.

במסך הראשי יש כרטיס לכל לוח, עם שורת סיכום קצרה (למשל "ממתינים לך ₪429.90"). לחיצה על כרטיס פותחת את הלוח, והחץ למעלה מחזיר לפתקים.
בכל לוח: **+** מוסיף פריט, ולחיצה על פריט פותחת אותו לעריכה. מוחקים בהחלקה ימינה או בכפתור "מחיקה" בחלון העריכה, ובשני המקרים יש **ביטול**.

### 🚗 רכב

טסט, ביטוח חובה, ביטוח מקיף, ביטוח צד ג׳, רישיון רכב (או כל דבר אחר). לכל אחד רושמים **בתוקף עד**, ואפשר גם חברה או סוכן ועלות.
- הרשימה ממוינת לפי מה שפג ראשון. תאריך קרוב נצבע בכתום, ותאריך שעבר באדום ("פג תוקף לפני…").
- **התראה לפני פקיעת תוקף** (כפתור בראש הלוח): שבוע / שבועיים / חודש (ברירת המחדל) / חודשיים לפני.
- כשמגיע הזמן: משימה "לחדש טסט" במסך היום (עוברת ליום הבא עד שמטפלים), וכרטיס בראש הלוח עם כפתור **חידשתי**. הכפתור פותח את הפריט עם תאריך תוקף חדש של שנה קדימה; שומרים, והמשימה מסומנת לבד כבוצעה.

### 💊 גלולות

21 ימי כדורים ו-7 ימי הפסקה, וחוזר. רושמים **פעם אחת** מתי התחלת את החפיסה הנוכחית (הכפתור "מתי התחלתי את החפיסה?"), וכל השאר מחושב לבד.

- **כרטיס מצב:** "כדור 12 מתוך 21" או "הפסקה · יום 3 מתוך 7", פס התקדמות, ומתי מתחילה ההפסקה או החפיסה הבאה.
- **לחבר חפיסה (בלי הפסקה):** כפתור מתחת לכרטיס בזמן חפיסה. החפיסה הבאה מתחילה מיד, וההפסקה זזה לסוף שלה. **ביטול החיבור** מחזיר את ההפסקה.
- **מקסימום 2 חפיסות ברצף:** בחפיסה השנייה ברצף הכפתור לא מופיע, ובמקומו "אחריה הפסקה". אם בכל זאת נרשמה חפיסה שלישית ברצף (למשל בתאריך ידני), מופיעה אזהרה אדומה.
- **ההפסקות הבאות:** תחזית של 8 ההפסקות הקרובות, עם "בעוד X". מתעדכנת כשמחברים חפיסות.
- **בלוח השנה** מסומנים **רק ימי ההפסקה**, בקו ורוד דקיק ועדין מתחת למספר. כשבוחרים יום כזה, ליד התאריך כתוב "הפסקה · יום 3 מתוך 7".
- **ימי מעבר כמשימות:** ביום שבו מתחילה הפסקה מופיעה משימה "💊 מתחילה הפסקה", וביום שבו מתחילה חפיסה – "💊 מתחילה חפיסה חדשה" (או "מחוברת"). אחרי 2 חפיסות ברצף המשימה אומרת "לא לחבר". המשימות נוצרות 5 שבועות מראש, מתעדכנות כשהתוכנית משתנה, ולא עוברות ליום הבא בחצות.
- **חפיסה בתאריך אחר מהמתוכנן:** לוחצים על + ורושמים את התאריך. התוכנית ממשיכה ממנו. רשימת "חפיסות שהתחילו" מראה את מה שנרשם, ואפשר למחוק בהחלקה.

### תזכורת לקביעת תור

בשיער ובריסים יש כפתור **🔔 תזכורות לקביעת תור** בראש הלוח. שם בוחרים לכל סוג טיפול כל כמה זמן קובעים תור (כל חודש עד כל 12 חודשים, או בלי תזכורת), ומתי להזכיר: ביום עצמו, שבוע לפני, שבועיים לפני (ברירת המחדל) או חודש לפני.

ההגדרות שמוכנות מראש: **גוונים כל 6 חודשים**, **פתיחת תלתלים כל 4 חודשים**, **הרמת ריסים** ו**הרמת גבות כל 3 חודשים**.

כשמתקרב מועד התור הבא (לפי התור האחרון שכבר היה) ועוד לא קבעת תור:
- במסך **היום** מופיעה משימה, למשל "לקבוע תור גוונים". היא עוברת ליום הבא כל עוד לא טיפלת בה.
- בראש הלוח מופיע כרטיס כתום **"הגיע הזמן לקבוע תור"** עם כפתור **קביעת תור**. הכפתור פותח תור חדש עם סוג הטיפול ותאריך מוצע.
- במסך "פתקים" הכרטיס של הלוח מראה "🔔 לקבוע תור גוונים".

כשקובעים תור, המשימה "לקבוע תור" מסומנת לבד כבוצעה. אם מוחקים אותה, היא לא חוזרת עד התור הבא.
התזכורת מתחילה רק אחרי שיש תור קודם מהסוג הזה, כי לפיו מחושב מועד התור הבא.
ההגדרות נשמרות במכשיר שבו בחרת אותן.

### תורים עתידיים ולוח השנה

- תור בשיער או בריסים עם תאריך מהיום והלאה **נכנס אוטומטית ללוח השנה** כמשימה, למשל "תור גוונים", עם השעה אם הזנת.
- **שינוי התאריך או השעה** של התור מזיז גם את המשימה. ולהפך: גרירת המשימה בלוח השנה לתאריך אחר מעדכנת את התור.
- **מחיקת התור** מוחקת גם את המשימה, ו**ביטול** מחזיר את שתיהן.
- משימה של תור לא עוברת ליום הבא בחצות, כמו משימות רגילות. היא נשארת ביום של התור.
- במסך "פתקים", כשיש תור עתידי, הכרטיס של הלוח מראה אותו בצבע ההדגשה, למשל "📅 תור גוונים · בעוד 12 ימים".

## תת-משימות בשורה

למשימה עם תת-משימות יש בצד שמאל של השורה כפתור קטן, למשל **☑ 0/9**. לחיצה עליו פותחת את תת-המשימות מתחת למשימה, ואפשר לסמן אותן ישר משם, בלי להיכנס לחלון העריכה.
בחלון העריכה, תת-המשימות מופיעות מיד מתחת לכותרת, לפני כל ההגדרות.

**כשמסמנים את כל תת-המשימות, המשימה עצמה מסומנת לבד כבוצעה** (עם **ביטול** בהודעה). אם מבטלים סימון של תת-משימה במשימה שכבר בוצעה, המשימה חוזרת להיות פתוחה.

## סיכום

המסך **סיכום** (בסרגל התחתון ובתפריט):
- **ארבעה מספרים:** כמה הושלמו היום, כמה הושלמו ב-7 הימים האחרונים, כמה משימות פתוחות, וממוצע ימי הדחייה למשימה שהושלמה.
- **גרף** של המשימות שהושלמו בכל אחד מ-7 הימים האחרונים. "היום" בצד שמאל. נגיעה בעמודה או מעבר עם העכבר מראים את המספר והתאריך.
- **נדחו הכי הרבה:** חמש המשימות הפתוחות עם הכי הרבה ימי דחייה. לחיצה על משימה פותחת אותה לעריכה.

## סל מחזור

- משימה שנמחקת עוברת ל**סל מחזור** (בתחתית התפריט) ונשמרת שם 30 יום. אחרי זה היא נמחקת לגמרי.
- **שחזור** מחזיר את המשימה למקום שלה. **מחיקה** מוחקת אותה לצמיתות. **ריקון הסל** מוחק את כולן.
- ליד "סל מחזור" בתפריט מופיע כמה משימות יש בו.

## שכפול משימה

שימושי למשימה שחוזרת מספר ידוע של פעמים, למשל כדור שלוקחים במשך 15 יום:

1. יוצרים משימה אחת, למשל "לקחת כדור", בתאריך שבו מתחילים.
2. לוחצים עליה, ובחלון העריכה לוחצים **שכפול** (למטה, ליד "מחיקה").
3. בוחרים:
   - **עד מתי:**
     - **מספר פעמים:** כמה פעמים בסך הכול, כולל המשימה המקורית. למשל 15.
     - **עד תאריך:** בוחרים את התאריך האחרון, ומספר הפעמים מחושב לבד.
       מתחת לתאריך מופיע, למשל, "יום חמישי, 3 בדצמבר · 15 פעמים בסך הכול".
   - **כל יום** או **כל שבוע**.
   - **מספור:** אם מסומן, המשימות ייקראו "לקחת כדור 1", "לקחת כדור 2" וכן הלאה. גם המקורית מקבלת את המספר 1.
     התצוגה המקדימה מראה איך השמות ייראו.
4. בתחתית מופיעה תצוגה מקדימה: הראשונה, השנייה והאחרונה, עם התאריכים.
5. לוחצים **יצירת 15 משימות**. אם טעית, יש כפתור **ביטול** בהודעה שמופיעה.

העותקים מקבלים את העדיפות, הרשימה וההערות של המשימה המקורית. אחרי היצירה כל עותק הוא משימה רגילה ועצמאית.

## עבודה עם משימות

- **סימון כבוצעה:** לוחצים על העיגול. מופיעה הודעה עם כפתור **ביטול** למקרה של טעות.
  הודעות עם "ביטול" נשארות 3 שניות, והודעות רגילות פחות מ-2 שניות. משימה שנמחקה אפשר לשחזר גם אחרי שההודעה נעלמה, מסל המחזור.
- **עריכה:** לוחצים על שם המשימה. בחלון שנפתח אפשר לשנות כותרת, תאריך יעד (רק היום או תאריך עתידי), עדיפות, רשימה והערות.
  אם המשימה נדחתה, החלון מראה גם את מספר ימי הדחייה.
  השינויים נשמרים מיד, אין צורך ללחוץ "שמירה".
- **מחיקה:** בחלון העריכה, **מחיקה**. אפשר לבטל דרך ההודעה שמופיעה.
- **צבע העיגול** מראה את העדיפות:

  | עיגול | עדיפות |
  |---|---|
  | אפור | ללא עדיפות |
  | בצבע ההדגשה (לבנדר כברירת מחדל) | נמוכה |
  | כתום | בינונית |
  | אדום | גבוהה |

  משנים עדיפות בחלון העריכה, או בזמן ההוספה עם `!`, `!!` או `!!!`.
- **סדר המשימות:** לפי תאריך יעד (משימות בלי תאריך בסוף), ואז לפי עדיפות.

## רשימות

- **רשימה חדשה:** בתפריט, **+ רשימה חדשה**.
- **שינוי שם, צבע או מחיקה:** פותחים את הרשימה ולוחצים על ⋮ בראש המסך.
  כשמוחקים רשימה, המשימות שבה לא נמחקות. הן עוברות ל"ללא רשימה".

## חיפוש

לוחצים על זכוכית המגדלת. החיפוש מחפש בכותרות ובהערות, גם במשימות שהושלמו.

## הגדרות

- **סנכרון בין מכשירים:** התחברות והרשמה. אפשרי רק אחרי שהוגדר Supabase (ראו [התקנה ופריסה](setup-and-deploy.md)).
- **התקנה כאפליקציה:** כפתור התקנה, או הסבר איך להתקין במכשיר שבו אתם נמצאים.
- **צבע:** צבע ההדגשה של האפליקציה: לבנדר (ברירת המחדל), מרווה, אפרסק או ורוד עתיק.
  הצבע חל על כפתור ה-+, הלוח, הסימונים והכפתורים. הבחירה נשמרת בדפדפן שבו בחרת.
- **נתונים:**
  - **ייצוא גיבוי:** מוריד קובץ JSON עם כל המשימות, הרשימות והפתקים.
  - **ייבוא גיבוי:** טוען קובץ כזה. משימות קיימות עם אותו מזהה מוחלפות.
  - **מחיקת משימות שהושלמו:** מוחק את כל המשימות שסומנו כבוצעו.

## איפה הנתונים נשמרים

- **בלי התחברות:** רק בדפדפן שבו עובדים. דפדפן אחר או מכשיר אחר לא יראו את אותן משימות.
  ניקוי נתוני הגלישה בדפדפן מוחק גם את המשימות, אז כדאי לייצא גיבוי מדי פעם.
- **עם התחברות:** במכשיר וגם בחשבון (Supabase). כל שינוי מגיע לשאר המכשירים תוך שניות.
  - בלי אינטרנט ממשיכים לעבוד כרגיל, והשינויים נשלחים כשהחיבור חוזר.
  - מצב הסנכרון מוצג בתחתית תפריט הצד: "מסונכרן", "מסנכרן…", "אין חיבור" או "שגיאת סנכרון".
  - כשמתנתקים, המשימות נמחקות מהמכשיר הזה אבל נשארות בחשבון.
